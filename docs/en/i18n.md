# i18n

two languages: **en** and **ru**

## docs

same files in two folders — pick your language:

| english | russian |
|---------|---------|
| [docs/en/](en/README.md) | [docs/ru/](ru/README.md) |
| [docs/en/checks/](en/checks/universal.md) | [docs/ru/checks/](ru/checks/universal.md) |

no mixed-language files inside one markdown

## cli output

| file | purpose |
|------|---------|
| [locales/en.yaml](../../locales/en.yaml) | cli strings, english |
| [locales/ru.yaml](../../locales/ru.yaml) | cli strings, russian |

keys must exist in both files

## choosing language

1. flag `--lang en` or `--lang ru`
2. env `REFGRADE_LANG`
3. `lang:` in `.refgrade.yaml`

precedence: flag > env > yaml > `en`

report still prints file paths and symbol names as in source code
